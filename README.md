# Nếu Một Ngày — What If 60 giây

Trang lưu trữ các tập What If 60 giây "Nếu một ngày": người xem tìm tập theo chủ đề, xem lại từng tập và gợi ý chủ đề mới.

> Lưu ý: đây là bản demo. Danh sách tập, hình ảnh và bình luận hiển thị trên trang là dữ liệu mẫu, chưa phải nội dung phát hành chính thức.

## Demo trực tuyến

- https://m-software-neu-mot-ngay.genalpha.dev

## Cách xem / chạy

Mở file `index.html` bằng trình duyệt, hoặc chạy một máy chủ tĩnh tại thư mục gốc:

```bash
python3 -m http.server 8000
```

rồi mở http://localhost:8000.

## Các tệp chính

| Tệp | Vai trò |
| --- | --- |
| `index.html` | Trang chính: danh sách tập, lọc theo chủ đề, xem từng tập, form gợi ý chủ đề |
| `README.md` | Tài liệu này |
| `LICENSE` | Giấy phép MIT |

## English summary

"If One Day" is an archive site for 60-second What If episodes: browse episodes by topic, rewatch each episode, and suggest new topics.
